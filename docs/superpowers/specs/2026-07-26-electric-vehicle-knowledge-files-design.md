# 电动汽车多格式知识文件设计

## 目标

在 `data` 目录中新增或替换六种可被项目加载的中文知识文件：PDF、Markdown、DOCX、CSV、XLSX、PPTX。六个文件分别覆盖不同主题，内容由真实中文网络来源整合，不复制当前 `data` 目录已有 TXT、HTML 或误下载 PDF 的正文。

## 内容范围

| 格式 | 主题 | 内容重点 |
| --- | --- | --- |
| PDF | 汽车 OTA 升级与网络安全合规 | 软件升级分类、备案与召回责任、网络安全管理要求、车主注意事项 |
| Markdown | 动力电池回收、梯次利用与溯源管理 | 责任主体、回收流程、梯次利用条件、再生利用、溯源制度 |
| DOCX | 新能源汽车专属保险条款与理赔边界 | 专属险结构、常见责任、除外责任、充电设备与事故理赔材料 |
| CSV | 电驱动系统核心部件知识表 | 部件名称、功能、工作原理、关键参数、典型风险、资料来源 |
| XLSX | 中国充电基础设施统计指标与趋势分析 | 官方统计指标、年度或月度变化、同比计算、来源与口径说明 |
| PPTX | 车网互动 V2G 原理、应用场景与试点政策 | 双向充放电、参与主体、应用价值、关键约束、国家试点方向 |

## 来源与写作规则

1. 优先使用中国政府网、工业和信息化部、国家发展改革委、国家能源局、市场监管总局、中国保险行业协会及国家标准信息公共服务平台等权威中文来源。
2. 对统计数据保留原始数值、统计周期和口径，不推测缺失数据；计算值明确标注为计算结果。
3. 每个文件记录来源名称、原始网址和检索日期。CSV、XLSX 使用专门的来源列或来源工作表；PPTX 在备注中记录逐页来源。
4. 内容使用重新组织后的中文表述，仅在必要时引用短句；不大段复制网页正文。
5. 避开现有资料已覆盖的选购、日常充电与续航、维护保养、常见故障和基础问答内容。

## 文件处理

- 保留用户当前留在 `data` 目录中的 TXT 文件，不修改其内容。
- 不恢复用户已经手动删除的下载文件。
- 将上次误下载的 `电动汽车安全指南.pdf` 替换为新编 PDF，并采用与新主题对应的文件名。
- 不修改项目加载器或其他业务代码。

## 验收标准

1. `data` 目录最终包含 TXT、PDF、MD、DOCX、CSV、XLSX、PPTX 七类当前需要保留的格式；HTML 是否存在以用户手动删除后的状态为准。
2. 六个新文件均能被对应解析器正常打开并提取中文文本。
3. CSV 使用 UTF-8 编码；XLSX、DOCX、PPTX 为有效 OOXML 文件。
4. PDF、DOCX、XLSX、PPTX 完成渲染检查，无乱码、裁切、重叠或空白内容。
5. 六个主题彼此独立，并与原有 TXT 的主题边界保持明显区分。
6. 所有外部事实和数据均可从文件内记录的网址追溯。
