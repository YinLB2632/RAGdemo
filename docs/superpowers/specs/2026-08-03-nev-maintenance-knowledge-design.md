# 新能源汽车保养知识资料设计

## 目标

在 `data/` 中补充六份可直接被现有 RAG 读取的中文纯文本资料，作为已有通用《维护保养》和《故障排除》的专题补充。

## 文件与边界

| 文件 | 内容边界 |
| --- | --- |
| `动力电池日常使用与健康检查.txt` | 充电区间、温度、底盘碰撞、SOH 和异常升级处理 |
| `充电安全与充电设备日常检查.txt` | 插拔、家用设备、公共桩、异常停止充电 |
| `高压系统安全与送修边界.txt` | 高压危险识别、禁止自行操作的范围、事故后处置 |
| `热管理与空调系统保养.txt` | 冷却液、空调滤芯、冬夏季检查和异常信号 |
| `制动轮胎与底盘保养.txt` | 再生制动影响、轮胎载荷与胎压、底盘检查 |
| `雨季涉水与长期停放维护.txt` | 涉水后禁忌、雨季检查、长期停放与低压电池维护 |

不包含品牌专用操作步骤、维修拆解、具体零件规格或未核实的固定保养周期；这些内容必须以车辆随车手册和授权服务中心要求为准。

## 内容结构

每份文件采用相同结构：适用范围、日常检查清单、异常或高风险情形、何时停止使用并联系专业人员、来源与复核入口。与已有文件重合的基础说明只保留必要引用，专题内容优先提供可检索的症状、风险和处理边界。

## 来源与可追溯性

每份资料末尾列出官方或专业机构的公开入口，包括国家消防救援局、国家市场监督管理总局、工信部、交通运输部、国家标准信息公共服务平台及车辆制造商用户手册页面。当前浏览器检索桥接不可用，资料中不把未能逐页复核的链接表述为实时检索结果；使用者需在车型或法规问题上复核最新版原始资料。

## 验收

1. 六个文件均为 UTF-8 `.txt`，位于 `data/` 根目录。
2. 文件名和内容不与现有资料重复，且每份包含安全边界和来源段落。
3. 文件符合项目支持的格式；读取验证确认存在、非空、UTF-8 可解码。
4. 运行现有测试，确认资料新增未影响代码行为。
